# Plant license record

Every 3D plant in Grove comes from FABOTANIC by AMIX, a web plant generator (https://amix-design.com/tl/fab-botanic/). This file records, for each plant you export, which version of FABOTANIC's license terms applied on the day you exported it. Add one row per export, at export time. A later license version applies only to assets exported under it, so the version on each row is the evidence for which terms cover that model.

## License summary (checked 2026-09-29)

FABOTANIC publishes its terms as "License and Terms of Use", version 1.0.0 at the time of writing. This summary is not legal advice. Re-read the current terms before each release.

**Allowed**

- Bundling the generated models in a free or commercial app
- Converting the models to other formats (GLB to USDZ)
- Editing their shape or color
- No fee and no required credit

**Forbidden**

- Distributing the models as the product itself: asset packs, asset collections, NFTs and similar, free or paid
- Posting a model as a standalone item on a user-generated-content platform
- Using the models in an AI training set
- Feeding the models into another plant generator or 3D generator

**What this means for Grove**

- The app never offers share, export or download of a model file.
- Do not upload plant files to online converters or to any 3D or plant generator.
- Model files in a public repository can be downloaded on their own. Check the terms before you make this repository public.
- Optional credit, recommended by the terms but not required: "Plant models: FABOTANIC (AMIX)"

**License URL**

Fill in the License URL column from FABOTANIC's terms page. The terms are reached from the tool page, and no separate address for them could be confirmed on 2026-09-29. If the terms page has its own address, paste that. If it does not, paste the tool page address, https://amix-design.com/tl/fab-botanic/, and write the license version you read on the page in the License version column.

## Filling in a row

| Column | What to write |
|---|---|
| Plant ID | The ID from the file names, such as `fern-a-01` |
| FABOTANIC version | The tool version, if the tool page shows one. If it does not, write `not shown`. |
| License version | The version number printed on the terms page on the export date |
| Export date | `YYYY-MM-DD` |
| Settings JSON | Path to the saved settings file, such as `Assets/Plants/source/fern-a-01.json` |
| Triangles | FABOTANIC's triangle readout for the exported plant |
| Height (m) | FABOTANIC's height readout, the same number as `heightMeters` in `plants.json` |
| Visual check | `pass` with where you checked (Simulator, iPhone), or `fail` with the reason in Notes |
| Notes | Anything unusual, such as "repaired in Blender 5.2: leaf alpha set to cutout" |
